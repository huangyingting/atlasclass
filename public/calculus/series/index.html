Chapter 10 · Infinite series

adding forever, and arriving

An infinite series adds infinitely many numbers. It can still have a finite sum: when the running totals settle on one number, that number is the sum.

The tower stacks slabs 3, 2, 4/3, 8/9, …, each two-thirds as tall as the one below. There is no last slab, yet the stack never reaches 9, and gets as close to 9 as you like.

This chapter asks when an infinite sum exists (a set of tests for convergence), how far a partial sum can be from it (error bounds), and then turns the idea around: functions such as ex and sin x written as power series, polynomials that never end.

The whole unit is AP Calculus BC only.

10.1 · Convergent and divergent series

the sum is a limit

The nth partial sum Sn = a1 + a2 + ⋯ + an is an ordinary sum. The series ∑an\sum a_n converges to S if lim⁡n→∞Sn=S\lim_{n\to\infty} S_n = S; if the partial sums have no finite limit, it diverges.

Take ∑n=1∞1n(n+1)\sum_{n=1}^{\infty} \frac{1}{n(n+1)}. Each term splits as 1n−1n+1\frac1n - \frac1{n+1}, so the middle of every partial sum cancels:

Sn=(1−12)+(12−13)+⋯+(1n−1n+1)=1−1n+1\begin{aligned} S_n &= \left(1 - \tfrac12\right) + \left(\tfrac12 - \tfrac13\right) + \cdots \\ &\quad + \left(\tfrac1n - \tfrac1{n+1}\right) \\ &= 1 - \frac{1}{n+1} \end{aligned}

So S4 = 0.80, S99 = 0.99, and Sn → 1: the series converges to 1.

∑n=0∞(−1)n\sum_{n=0}^{\infty} (-1)^n has partial sums 1, 0, 1, 0, …, which never settle: it diverges. So does ∑n\sum n, whose partial sums grow without bound.

10.2 · Geometric series

the same ratio every time

A geometric series multiplies by the same ratio r from each term to the next: a + ar + ar² + ⋯. It converges exactly when |r| < 1, and then

∑n=0∞arn=a1−r,∣r∣<1\sum_{n=0}^{\infty} a r^n = \frac{a}{1-r}, \qquad |r| < 1

The reason: SN=a 1−rN1−rS_N = a\,\frac{1-r^N}{1-r}, and rN → 0 only when |r| < 1. When |r| ≥ 1 the terms don’t shrink to 0, and the series diverges.

The tower is ∑n=0∞3(23)n\sum_{n=0}^{\infty} 3\left(\tfrac23\right)^n: a = 3, r = 2/3, so the sum is 31−2/3=9\frac{3}{1 - 2/3} = 9.

10.3 · The nth term test

terms that don’t shrink

If the terms of a series don’t approach 0, the series diverges: if lim⁡n→∞an≠0\lim_{n\to\infty} a_n \ne 0 or the limit doesn’t exist, then ∑an\sum a_n diverges.

The reason: if the partial sums converge to S, then an=Sn−Sn−1→S−S=0a_n = S_n - S_{n-1} \to S - S = 0.

Take ∑n=1∞n2n+1\sum_{n=1}^{\infty} \frac{n}{2n+1}. Its terms head to lim⁡n2n+1=12≠0\lim \frac{n}{2n+1} = \frac12 \ne 0, so it diverges. In the figure each new term adds almost ½ (the blue bars level off), and the partial sums climb a straight ramp: S16 = 7.30, with no ceiling.

The test only ever proves divergence. If an → 0 it says nothing: 1/n → 0, yet ∑1n\sum \frac1n diverges (10.5), while 1/n² → 0 and ∑1n2\sum \frac1{n^2} converges. Use it first, as a quick check, then reach for another test.

10.4 · The integral test

a series and an area

If f is positive, continuous and decreasing for x ≥ 1, and an = f(n), then ∑n=1∞an\sum_{n=1}^{\infty} a_n and ∫1∞f(x) dx\int_1^{\infty} f(x)\,dx both converge or both diverge.

Draw term n as a bar of width 1 on [n − 1, n]. Because f is decreasing, bars 2, 3, 4, … fit under the curve from 1 on, so a finite area holds them all; and an infinite area is too big for them.

Take ∑n=1∞1n2+1\sum_{n=1}^{\infty}\frac{1}{n^2+1}. On [1, ∞), f(x) = 1/(x² + 1) is positive, continuous and decreasing, and

∫1∞dxx2+1=lim⁡b→∞[arctan⁡x]1b=π2−π4=π4\begin{aligned} \int_1^{\infty}\frac{dx}{x^2+1} &= \lim_{b\to\infty}\Big[\arctan x\Big]_1^b \\ &= \frac{\pi}{2} - \frac{\pi}{4} = \frac{\pi}{4} \end{aligned}

The integral is finite, so the series converges. The integral is not the sum: the bars only pin it between π4\frac{\pi}{4} and 12+π4\frac12 + \frac{\pi}{4}, that is 0.785 < S < 1.285. (In fact S ≈ 1.077.)

10.5 · Harmonic series and p-series

converges when p > 1

A p-series ∑n=1∞1np\sum_{n=1}^{\infty} \frac{1}{n^p} converges if p > 1 and diverges if p ≤ 1.

It follows from the integral test: ∫1∞x−p dx\int_1^{\infty} x^{-p}\,dx is finite exactly when p > 1.

The harmonic series is p = 1: ∑1n=1+12+13+⋯\sum \frac1n = 1 + \frac12 + \frac13 + \cdots diverges, though its terms go to 0. Its partial sums (red) grow like ln n, so slowly that H40 = 4.28 and passing 10 takes 12,367 terms. But they never stop.

p = 2 converges (blue): S40 = 1.620, and the sum is π26\frac{\pi^2}{6} = 1.645.

10.6 · Comparison tests

against a series you know

Direct comparison. If 0 ≤ an ≤ bn: when ∑bn\sum b_n converges, so does ∑an\sum a_n; when ∑an\sum a_n diverges, so does ∑bn\sum b_n.

1n2+3<1n2\frac{1}{n^2+3} < \frac{1}{n^2}, and ∑1n2\sum \frac{1}{n^2} converges (a p-series), so ∑1n2+3\sum \frac{1}{n^2+3} converges: every red bar stands inside a blue one.

Limit comparison. If an, bn > 0 and lim⁡anbn=L\lim \frac{a_n}{b_n} = L with 0 < L < ∞, the two series both converge or both diverge.

12n−1\frac{1}{2^n - 1} is larger than 12n\frac1{2^n}, so direct comparison with the convergent ∑12n\sum \frac{1}{2^n} proves nothing. But

lim⁡n→∞1/(2n−1)1/2n=lim⁡n→∞2n2n−1=1\lim_{n\to\infty} \frac{1/(2^n-1)}{1/2^n} = \lim_{n\to\infty} \frac{2^n}{2^n - 1} = 1

is positive and finite, so ∑12n−1\sum \frac{1}{2^n-1} converges too. Compare with the terms’ dominant parts: a geometric series or a p-series.

10.7 · The alternating series test

signs that take turns

An alternating series ∑(−1)n+1bn\sum (-1)^{n+1} b_n with bn > 0 converges if the bn are decreasing and lim⁡n→∞bn=0\lim_{n\to\infty} b_n = 0.

Each step goes the opposite way to the last and is shorter, so the partial sums zigzag in narrowing swings around one number, and close in on it.

Take the alternating harmonic series 1 − ½ + ⅓ − ¼ + ⋯. Here bn = 1/n decreases to 0, so it converges. (Its sum is ln 2 ≈ 0.6931, from the series for ln(1 + x).)

10.8 · The ratio test

each term against the last

Let L=lim⁡n→∞∣an+1an∣L = \lim_{n\to\infty} \left|\frac{a_{n+1}}{a_n}\right|. If L < 1 the series converges (absolutely); if L > 1 or L = ∞ it diverges; if L = 1 the test is inconclusive.

When L < 1, the terms eventually shrink at least as fast as a geometric series with a ratio below 1.

Take ∑n=1∞n3n\sum_{n=1}^{\infty} \frac{n}{3^n}:

∣an+1an∣=n+13n+1⋅3nn=n+13n→13\left|\frac{a_{n+1}}{a_n}\right| = \frac{n+1}{3^{n+1}}\cdot\frac{3^n}{n} = \frac{n+1}{3n} \to \frac13

L = ⅓ < 1, so the series converges (its sum is 0.75). The red dots are the ratios, 0.667, 0.500, 0.444, …, settling on ⅓, well under the grey line at 1.

The ratio test suits factorials and powers such as n! and 3n. It fails on p-series: ∑1n\sum\frac1n and ∑1n2\sum\frac1{n^2} both give L = 1, yet one diverges and the other converges.

10.9 · Absolute or conditional convergence

with the signs, and without

∑an\sum a_n converges absolutely if ∑∣an∣\sum |a_n| converges. Absolute convergence implies convergence. A series that converges while ∑∣an∣\sum |a_n| diverges converges conditionally.

The alternating harmonic series converges (alternating series test), but its sizes form the harmonic series, which diverges: it converges conditionally.

So test ∑∣an∣\sum |a_n| first. If it converges: absolute. If not, test the signed series; if that converges: conditional.

10.10 · Alternating series error bound

no further off than the next term

If an alternating series meets the conditions of the alternating series test, stopping after n terms is off by at most the first term left out:

∣S−Sn∣≤bn+1|S - S_n| \le b_{n+1}

The sum always lies between two consecutive partial sums Sn and Sn+1 (the blue band), and they are exactly bn+1 apart.

For 1 − ½ + ⅓ − ¼ + ⋯:

S4=1−12+13−14=712∣S−S4∣≤b5=15\begin{aligned} S_4 &= 1 - \tfrac12 + \tfrac13 - \tfrac14 = \tfrac{7}{12} \\ |S - S_4| &\le b_5 = \tfrac15 \end{aligned}

S4 ≈ 0.5833, and the true error is ln 2 − 7/12 = 0.1098, within 0.2. The next term, +⅕, is positive, so S4 is an underestimate.

To be within 0.01 you need 1n+1≤0.01\frac{1}{n+1} \le 0.01, so n = 99 terms.

10.11 · Taylor polynomials

matching derivatives at a point

The Taylor polynomial of degree n for f about x = a matches f and its first n derivatives at a:

Pn(x)=∑k=0nf(k)(a)k!(x−a)kP_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k

that is, f(a)+f′(a)(x−a)+f′′(a)2!(x−a)2+⋯f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \cdots: the coefficient of (x − a)k is the kth derivative over k!. About a = 0 it is also called a Maclaurin polynomial.

Take f(x) = ex about 0. Every derivative is ex, so every f(k)(0) = 1:

P3(x)=1+x+x22+x36P_3(x) = 1 + x + \frac{x^2}{2} + \frac{x^3}{6}

At x = 1: P3(1) = 8/3 ≈ 2.6667, against e ≈ 2.7183. In the figure each new degree (red) hugs ex over a wider stretch around 0, and is worst far from it.

10.12 · Lagrange error bound

how far off Pₙ can be

If |f(n+1)(z)| ≤ M for every z between a and x, then

∣f(x)−Pn(x)∣≤M ∣x−a∣n+1(n+1)!|f(x) - P_n(x)| \le \frac{M\,|x-a|^{n+1}}{(n+1)!}

Bound the error of P3(1) = 8/3 for e. The fourth derivative is ez, at most e < 3 on [0, 1], so take M = 3:

∣e−P3(1)∣≤3⋅144!=0.125|e - P_3(1)| \le \frac{3\cdot 1^4}{4!} = 0.125

The true error, e − 8/3 = 0.0516, is under the bound. The figure magnifies both on [0, 1]: the true error ex − P3(x) (red) stays under 3x⁴/4! (blue) all the way.

Use the (n + 1)th derivative and (n + 1)!, never the nth; M must cover the whole interval from a to x.

10.13 · Radius and interval of convergence

where a power series converges

A power series ∑cn(x−a)n\sum c_n (x-a)^n converges for |x − a| < R, the radius of convergence, and diverges for |x − a| > R. Each endpoint must be checked on its own.

Take ∑n=1∞(x−2)nn⋅3n\sum_{n=1}^{\infty} \frac{(x-2)^n}{n\cdot 3^n}. The ratio test:

∣an+1an∣=∣x−2∣3⋅nn+1→∣x−2∣3\left|\frac{a_{n+1}}{a_n}\right| = \frac{|x-2|}{3}\cdot\frac{n}{n+1} \to \frac{|x-2|}{3}

This is less than 1 when |x − 2| < 3, so R = 3: the series converges on (-1, 5). Now the endpoints:

x = 5∑1n\sum \frac{1}{n}, harmonicdiverges
x = -1∑(−1)nn\sum \frac{(-1)^n}{n}, alternatingconverges

The interval of convergence is [-1, 5). Inside it the partial sums settle onto the sum; outside, they run away.

10.14 · Taylor and Maclaurin series

the polynomial that never ends

The Taylor series of f about a keeps every term: ∑f(n)(a)n!(x−a)n\sum \frac{f^{(n)}(a)}{n!}(x-a)^n. About 0 it is the Maclaurin series.

For sin x the derivatives at 0 repeat 0, 1, 0, −1, so only odd powers survive:

sin⁡x=x−x33!+x55!−⋯=∑n=0∞(−1)nx2n+1(2n+1)!\begin{aligned} \sin x &= x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots \\ &= \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{(2n+1)!} \end{aligned}

It converges for every x. Two terms give sin 0.5 ≈ 0.479167, against 0.479426.

10.15 · Representing functions as power series

new series from old

Known series make new ones: substitute, multiply by powers of x, or differentiate or integrate term by term. The radius stays; endpoints can change.

With u = −x² in 11−u=∑un\frac{1}{1-u} = \sum u^n:

11+x2=∑n=0∞(−1)nx2n,∣x∣<1\frac{1}{1+x^2} = \sum_{n=0}^{\infty} (-1)^n x^{2n}, \quad |x| < 1

Integrate from 0 (arctan 0 = 0, so the constant is 0):

arctan⁡x=∑n=0∞(−1)nx2n+12n+1\arctan x = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{2n+1}

At x = ½, three terms give ½ − 1/24 + 1/160 = 0.4646 (arctan ½ = 0.4636). Differentiating 11−x\frac1{1-x} gives 1(1−x)2=∑n=1∞nxn−1\frac{1}{(1-x)^2} = \sum_{n=1}^{\infty} n x^{n-1}.
