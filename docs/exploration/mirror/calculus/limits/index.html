Limits and continuity

Chapter 1 · Limits and continuity

approaching, without arriving

Every idea in calculus rests on one question: as the input heads toward a point, what value does the output head toward? That value is a limit.

The graph is y=sin⁡xxy = \dfrac{\sin x}{x}. At x = 0 the formula reads 0/0, which is no number at all, so the graph has a hole there. Yet the two points sliding in from either side rise toward the same height, 1:

lim⁡x→0sin⁡xx=1\lim_{x \to 0} \frac{\sin x}{x} = 1

The function never takes the value 1; it only gets as close to it as you like. A limit is about the approach, never the arrival.

This chapter shows how to find limits (from graphs, tables, algebra and squeezing), what it means for a function to be continuous, and the first theorem continuity buys.

1.1 · Change at an instant

can a rate exist at a single moment?

A rate of change compares two moments: how much the output changed over how much the input changed. At a single instant nothing has changed yet. A limit resolves this.

On y=x2y = x^2, the average rate of change from x = 1 to x = 1 + h is the slope of the red secant:

(1+h)2−12h=2h+h2h=2+h\frac{(1+h)^2 - 1^2}{h} = \frac{2h + h^2}{h} = 2 + h

1.2 · The limit

what f(x) approaches, not what f(c) is

lim⁡x→cf(x)=L\lim_{x\to c} f(x) = L means that f(x) stays as close to L as you like once x is close enough to c, with x ≠ c.

Read it “the limit of f(x) as x approaches c is L.” The input approaches from both sides, and the limit, if it exists, is one finite number.

Here f(x)=x2−1x−1f(x) = \dfrac{x^2 - 1}{x - 1} for x ≠ 1, and f(1) has been assigned the value 3. Away from 1, f(x) = x + 1, so the sliding points both head to 2:

lim⁡x→1f(x)=2,f(1)=3\lim_{x \to 1} f(x) = 2, \qquad f(1) = 3

The limit never looks at x = 1 itself. Change f(1) to 100, or leave it undefined, and the limit is still 2. The value at a point and the limit at that point are separate questions; when they agree, the function is continuous there (1.11).

1.3 · Limits from graphs

one side at a time

A one-sided limit lets x approach from one side only: x→c−x \to c^- from the left (x < c), x→c+x \to c^+ from the right.

The graph is g(x)=x2/2+1g(x) = x^2/2 + 1 for x < 2 and g(x)=x−1g(x) = x - 1 for x ≥ 2. Follow the curve toward x = 2 from each side and read the height it heads for:

lim⁡x→2−g(x)=3lim⁡x→2+g(x)=1=g(2)\begin{aligned} \lim_{x \to 2^-} g(x) &= 3 \\ \lim_{x \to 2^+} g(x) &= 1 = g(2) \end{aligned}

The two-sided limit exists only when both one-sided limits exist and are equal. Here 3 ≠ 1, so lim⁡x→2g(x)\lim_{x \to 2} g(x) does not exist.

Reading a graph: the open circle marks a height the curve approaches but does not take; the filled dot gives only the value g(2). A limit can also fail to exist when the graph grows without bound (1.14) or oscillates faster and faster, like sin⁡(1/x)\sin(1/x) near 0.

evidence, not proof

A table estimates a limit: take x closer and closer to c from both sides and watch where f(x) settles.

1.6 · Algebraic manipulation

factor, cancel, rationalize

When substitution gives 0/0, the expression is hiding a common factor. Rewrite it as a function that agrees with it everywhere except at c, then substitute.

Factor and cancel.

lim⁡x→2x2+x−6x−2=lim⁡x→2(x−2)(x+3)x−2=lim⁡x→2(x+3)=5\begin{aligned} &\lim_{x \to 2} \frac{x^2 + x - 6}{x - 2} \\ &= \lim_{x \to 2} \frac{(x - 2)(x + 3)}{x - 2} \\ &= \lim_{x \to 2} (x + 3) = 5 \end{aligned}

Rationalize: multiply top and bottom by the conjugate.

lim⁡x→4x−4x−2⋅x+2x+2=lim⁡x→4(x−4)(x+2)x−4=4\begin{aligned} &\lim_{x \to 4} \frac{x - 4}{\sqrt{x} - 2} \cdot \frac{\sqrt{x} + 2}{\sqrt{x} + 2} \\ &= \lim_{x \to 4} \frac{(x - 4)(\sqrt{x} + 2)}{x - 4} = 4 \end{aligned}

Cancelling is allowed because a limit at c only uses x ≠ c, where x − c ≠ 0. The graphs show the cost: the simplified function is the same line or curve, but the original has a hole at c.

Other rewrites follow the same idea: combine a compound fraction over a common denominator, or use a trig identity such as sin⁡2x=1−cos⁡2x\sin^2 x = 1 - \cos^2 x.

trapped between two that agree

If g(x)≤f(x)≤h(x)g(x) \le f(x) \le h(x) near c, and lim⁡x→cg(x)=lim⁡x→ch(x)=L\lim_{x\to c} g(x) = \lim_{x\to c} h(x) = L, then lim⁡x→cf(x)=L\lim_{x\to c} f(x) = L too.

1.9 · Multiple representations

graph, table and formula agree

A limit can be read from a graph, estimated from a table, or found from a formula. All three must give the same answer.

Take f(x)=sin⁡3xxf(x) = \dfrac{\sin 3x}{x} as x → 0.

If the views disagree, suspect the view: a table with too few rows, a graph window too coarse to show a hole. The algebra is the proof; the graph and table are how you check it.

1.10 · Types of discontinuities

removable, jump, infinite

A function is discontinuous at c when its graph breaks there. The kind of break is named by what the limits do.

Removable: the limit exists, but f(c) is undefined or different. x2−x−2x−2\frac{x^2 - x - 2}{x - 2} → 3 as x → 2, and the formula is undefined at 2: a hole.

Jump: both one-sided limits exist but differ. x + 1 for x < 1 and x − 2 for x ≥ 1: from the left 2, from the right −1.

Infinite: at least one one-sided limit is ±∞. 1x−1\frac{1}{x - 1} → −∞ from the left and +∞ from the right: a vertical asymptote.

Only a removable discontinuity can be fixed by changing a single value (1.13). A jump or an asymptote is a real break in the graph, whatever f(c) is.

1.11 · Continuity at a point

three conditions, one equation

f is continuous at x = c when lim⁡x→cf(x)=f(c)\lim_{x\to c} f(x) = f(c). That one equation holds three conditions, each of which can fail:

  1. f(c) is defined;
  2. lim⁡x→cf(x)\lim_{x\to c} f(x) exists (both one-sided limits agree);
  3. the two are equal.

Here f(x) = x + 1 for x ≤ 1 and 3 − x² for x > 1. Check each at c = 1:

f(1)=2lim⁡x→1−(x+1)=2lim⁡x→1+(3−x2)=2\begin{aligned} f(1) &= 2 \\ \lim_{x\to 1^-} (x + 1) &= 2 \\ \lim_{x\to 1^+} (3 - x^2) &= 2 \end{aligned}

All three hold, so f is continuous at 1, even with a corner there. Continuity means no break, not smoothness.

Earlier graphs each fail one condition: 1.6’s holes fail (1), 1.3’s jump fails (2), and 1.2’s misplaced dot fails (3).

1.12 · Continuity over an interval

no breaks from end to end

f is continuous on an open interval when it is continuous at every point of it. On a closed interval [a, b] the endpoints need only one side: lim⁡x→a+f(x)=f(a)\lim_{x\to a^+} f(x) = f(a) and lim⁡x→b−f(x)=f(b)\lim_{x\to b^-} f(x) = f(b).

Whole families are continuous at every point of their domains: polynomials, rational functions, roots and powers, sine and cosine, exponentials and logarithms. So are their sums, differences, products, quotients (where the bottom isn’t 0) and compositions.

9−x2\sqrt{9 - x^2} has domain [−3, 3] and is continuous on all of it; at ±3 only the inside limit exists, and it equals the value 0. The pen draws it in one stroke.

r(x)=x+1x2−4r(x) = \dfrac{x + 1}{x^2 - 4} is rational, so it is continuous everywhere except where it is undefined: on (−∞, −2), (−2, 2) and (2, ∞).

1.13 · Removing discontinuities

choosing the value that closes the gap

A removable discontinuity is repaired by defining f(c) to be the limit. A piecewise function is made continuous by choosing its constants so the pieces meet.

A hole. x2−x−2x−2\frac{x^2 - x - 2}{x - 2} becomes continuous at 2 when its value there is defined as 3, the limit.

A constant. Let f(x) = kx + 1 for x < 2 and x² − 1 for x ≥ 2. The value and right-hand limit are 3; the left-hand limit is 2k + 1. Continuity at 2 needs them equal:

lim⁡x→2−(kx+1)=f(2)2k+1=3 ⇒ k=1\begin{gathered} \lim_{x\to 2^-} (kx + 1) = f(2) \\ 2k + 1 = 3 \;\Rightarrow\; k = 1 \end{gathered}

The figure turns the red line through (0, 1) as k changes. Only at k = 1 does its open end land on the filled dot. Every other k leaves a jump.

With two unknown constants and two break points, write one such equation at each break and solve them together.

1.14 · Infinite limits

vertical asymptotes

lim⁡x→cf(x)=∞\lim_{x\to c} f(x) = \infty means f(x) grows past every bound as x → c. The limit still does not exist as a number; the ∞ says how it fails.

The line x = c is a vertical asymptote when either one-sided limit at c is ∞ or −∞.

For x+1x−2\dfrac{x + 1}{x - 2} at x = 2, substitution gives 3/0: the top heads to 3, the bottom to 0. The sign of the bottom decides the direction:

For a rational function, a zero of the denominator that does not cancel gives a vertical asymptote; one that cancels with the top gives a hole (1.10).

1.15 · Limits at infinity

horizontal asymptotes and growth rates

lim⁡x→∞f(x)=L\lim_{x\to\infty} f(x) = L means f(x) gets as close to L as you like once x is large enough. Then y = L is a horizontal asymptote. The same goes for x → −∞.

For a rational function, divide top and bottom by the highest power of x in the denominator:

lim⁡x→±∞3x2+4xx2+1=lim⁡x→±∞3+4/x1+1/x2=3\begin{aligned} \lim_{x\to\pm\infty} \frac{3x^2 + 4x}{x^2 + 1} &= \lim_{x\to\pm\infty} \frac{3 + 4/x}{1 + 1/x^2} \\ &= 3 \end{aligned}

Top degree lower: the limit is 0. Equal: the ratio of leading coefficients. Higher: no horizontal asymptote. The graph may cross its asymptote (this one does, at x = 0.75); an asymptote describes only the far ends: f(20) = 3.192, f(−20) = 2.793.

Growth rates. As x → ∞, every exponential bx (b > 1) outgrows every power xp, which outgrows ln x. So lim⁡x→∞x3/ex=0\lim_{x\to\infty} x^3/e^x = 0 and lim⁡x→∞ln⁡x/x=0\lim_{x\to\infty} \ln x / \sqrt{x} = 0.

1.16 · The Intermediate Value Theorem

a continuous graph can’t skip a value

If f is continuous on [a, b] and N is any number between f(a) and f(b), then f(c) = N for at least one c in (a, b).

A continuous graph can’t get from one height to another without passing every height between. The red level N sweeps between -1 and 5; wherever it is, the curve crosses it.

Example. Does x3−x−1=0x^3 - x - 1 = 0 have a solution in (1, 2)? Let f(x)=x3−x−1f(x) = x^3 - x - 1.

  • f is a polynomial, so it is continuous on [1, 2].
  • f(1) = -1 < 0 and f(2) = 5 > 0.
  • 0 is between them, so by the IVT there is a c in (1, 2) with f(c) = 0.

(It is c ≈ 1.3247.) The theorem says a solution exists, not where it is or how many there are. And continuity is essential: 1/x goes from −1 at x = −1 to 1 at x = 1 but is never 0.
